AdGuard Home High Availability for OPNsense

A signed OPNsense package repository for AdGuard Home service integration and authenticated configuration synchronization between high-availability nodes.

Current packages target OPNsense 26.7 on FreeBSD 15 amd64.

Install

Run these commands in an OPNsense shell:

install -d -m 0755 /usr/local/etc/pkg/keys
fetch -o /usr/local/etc/pkg/keys/adguardhome-ha.pub \
  https://hintay.github.io/opnsense-adguardhome-ha/adguardhome-ha.pub
fetch -o /usr/local/etc/pkg/repos/adguardhome-ha.conf \
  https://hintay.github.io/opnsense-adguardhome-ha/adguardhome-ha.conf
pkg update -f
pkg install os-adguardhome-ha

Refresh the OPNsense browser session, then open Services > AdGuard Home.

Packages

  • os-adguardhome-ha provides the OPNsense interface, service integration, and synchronization.
  • adguardhome provides the official AdGuard Home FreeBSD executable.
